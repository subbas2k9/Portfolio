# Subbas M — Modern Developer Portfolio

A high-performance, responsive personal developer portfolio with a sleek, dark aesthetic built for **Subbas M**, Full-Stack Software Engineer & Computer Engineering Specialist.

🌐 **Live Demo:** [https://subbas2k9.github.io/Portfolio/](https://subbas2k9.github.io/Portfolio/)

---

## 🚀 Key Features

- **Dark Void Aesthetic**: Deep void background (`#090D16`), frosted glassmorphism (`backdrop-filter: blur(16px)`), and electric neon cyan (`#00F2FE`) & emerald mint (`#10B981`) accents.
- **Interactive Canvas Mesh**: Dynamic background particles with cursor repulsion and ambient glow effects.
- **1-Click "Copy Email" Badge**: Interactive badge with dynamic floating toast notification (`subbas2k9@gmail.com`).
- **Interactive Developer CLI Terminal**: In-browser virtual shell emulator supporting commands like `help`, `about`, `skills`, `projects`, `contact`, `socials`, `sudo hire`, and `clear`.
- **Bento Grid Tech Stack**: Categorized visual showcase of languages, frameworks, and developer tools.
- **Featured Projects Grid**: Modern 3D hover cards with custom SVG architecture previews, tech badges, and modal overviews.
- **100% Pure Front-End**: Zero server or backend dependencies. Runs natively in any browser.

---

## 🛠️ Built With

- **HTML5**: Semantic markup & SEO / Open Graph meta tags.
- **Vanilla CSS3**: Custom design tokens, glassmorphism, flexbox, CSS grid, and keyframe animations.
- **Vanilla JavaScript (ES6+)**: Scroll spy, clipboard utility, canvas particle engine, and terminal CLI emulator.
- **Google Fonts**: *Inter*, *Space Grotesk*, and *JetBrains Mono*.
